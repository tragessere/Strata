# Strata Privacy Policy

Strata is an open source emulator front-end based on Lemuroid. It is distributed in two versions, free and Play.

## Analytics

Strata does not collect any analytics or telemetry data about users.

## File Access

Strata requests read-only file access to a local folder on your device to discover game files.

## Google Drive

The Play version of the app has Google Drive included, using App Data scope. This gives Strata access to only an application folder in the user's Google Drive, where it can read and write game save information. It does not have access to user files nor the files of other applications.

The free version of the app does not include any Google services.

## Third Party Services

The app makes network requests to third party services for functionality.

Both versions of the app use http://thumbnails.libretro.com/ to automatically find cover art for games in the user's library.

The free version of the app uses https://www.github.com/ to download the emulator cores. The Play version of the app bundles the cores in the initial download.
