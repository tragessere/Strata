# Strata

Strata is a fork from the [Lemuroid](https://github.com/swordfish90/lemuroid) open-source Android emulator. This is just some vibe-coded changes
that I wanted to see in the emulator. They are mostly updates to add features that I missed having
from the [Delta emulator](https://github.com/rileytestut/delta) on iOS.

## Changes from Lemuroid

- Re-designed and simplified the game selection screen
- Support for setting custom artwork for game covers
- Added support for Delta skins (only covers systems that Delta supports)
- Removed notification permissions
- Added ability to resolve save data sync conflicts
- Added options for deleting and importing game data
